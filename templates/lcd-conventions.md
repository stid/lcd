Key meanings:

- **artifact-root** — where LCD's durable artifacts live (`MAP.md`, `DECISIONS.md`, and the
  `work/<slug>/` per-work-item folders). Chosen once at onboarding; everything else derives from it.
- **map / decisions / work-item-dir** — resolved paths the suite reads; derived from `artifact-root`.
- **spec / living-spec** — the optional living current-state spec (`SPEC.md`, a capability index
  of what the system does *now*). `living-spec: off` by default — LCD behaves exactly as before
  and `SPEC.md` is never created. Set `living-spec: on` once the project has accrued enough
  behaviour that "what does this do now" is expensive to re-derive from the work-item chain; then
  `lcd:reconcile` folds each closed Standard/Deep work-item into `SPEC.md` at closeout, and
  `lcd:triage` reads the relevant surface section before scoping new work. `spec` is the
  resolved path, derived from `artifact-root`.
- **test-placement** — where the Deep lane's `/lcd:test-gen` must write tests so this
  project's runner actually collects them. `<area>`, `<Name>`, `<slug>`, `<surface>` are filled per test.
- **test-discovery-glob** — the runner's own include pattern; the reason placement matters.
- **scoped-test / bail / single-test** — commands the red-green loop uses; `{path}` and `{name}`
  are substituted. Use the explicit non-watch form so the autonomous loop never hangs.
- **gate** — the full lint + typecheck + test command for the final `T-final` task.
- **eval** — `applicable` or `n/a — <reason>` for the `EVAL` surface (Eval-Driven Development).
  `n/a` is correct for deterministic projects with no scored/LLM output.
- **maintenance-bundle** — the curated commands `/lcd:tidy` runs to keep things in order
  (e.g. the gate, a dependency audit, a lint/format pass). Semicolon-separated.

### Zone-scoped overrides (monorepos)

In a workspace where packages have different runners/placement, any test key may be scoped to a
path prefix with `key[<path-prefix>]:`. A scoped key overrides the bare key for targets under
that prefix; the **longest matching prefix wins**; the bare key stays the fallback. Example:

```
scoped-test[packages/api]: pnpm --filter @acme/api exec vitest run {path}
bail[packages/api]: pnpm --filter @acme/api exec vitest run --bail 1 {path}
test-placement[packages/api]: packages/api/tests/<slug>/<surface>.test.ts
```

The red-green loop and `/lcd:test-gen` resolve the zone from the path they operate on.
One artifact-root for the whole workspace; MAP.md Zones = the packages. See the plugin's
`docs/monorepos.md`.
